# Security Policy

## Supported Versions

Picturefish Obsidian Navigator has not published an installable release yet. Until the fork has completed runtime
namespacing and its first security review, development builds are unsupported and must not be used with production
vaults.

## Reporting a Vulnerability

Report issues specific to Picturefish Obsidian Navigator through private vulnerability reporting in this repository:

https://github.com/sykfar/picturefish-obsidian-navigator/security/advisories/new

If private reporting is unavailable, open a public issue asking for a private reporting channel and do not include
exploit details.

Include the affected Picturefish and upstream baseline versions, Obsidian version, platform, reproduction steps, and any
relevant synthetic sample-vault data. Do not attach production vault contents, credentials, or personal information.

If the vulnerability also affects the upstream Notebook Navigator project, report it privately to upstream as described
in [its security policy](https://github.com/johansan/notebook-navigator/security/policy). Coordinate disclosure between
both projects rather than publishing exploit details.

Security reports are reviewed before public disclosure. Fix timing depends on impact and release scope.
